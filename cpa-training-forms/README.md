# เติมแบบ ผส.2 / ผส.3 อัตโนมัติ

กรอกข้อมูลใน Excel ครั้งเดียว โปรแกรมจะพิมพ์ลงแบบฟอร์ม PDF ของสภาวิชาชีพบัญชี (ฉบับปรับปรุง 31 ต.ค. 2567) ให้ทั้ง 2 แบบ

| แบบ | ชื่อแบบ | โปรแกรมเติมให้ |
|---|---|---|
| **ผส.2** | รายงานการฝึกหัดงานสอบบัญชี | หน้าแรก + ตารางรายละเอียดการฝึกหัดงาน (ต่อใบให้เองถ้าหน้าเดียวไม่พอ) |
| **ผส.3** | คำรับรองของผู้ให้การฝึกหัดงาน | ข้อมูลผู้สอบบัญชี ระยะเวลาฝึก (นับเป็น ปี/เดือน/วัน ให้เอง) และความเห็น |

ช่องลายมือชื่อและกรอบ "สำหรับเจ้าหน้าที่" เว้นว่างไว้ ต้องเซ็นเองหลังพิมพ์

## ติดตั้ง

```
pip install -r requirements.txt
```

`pythainlp` จะติดตั้งหรือไม่ก็ได้ ถ้ามี โปรแกรมจะตัดบรรทัดภาษาไทยในตารางตรงรอยต่อคำ ถ้าไม่มี จะตัดตรงช่องว่างหรือหน้าสระ เ แ โ ใ ไ แทน

## วิธีใช้

1. สร้างไฟล์ Excel สำหรับกรอก (หรือเปิด `ตัวอย่างข้อมูล.xlsx` ที่มีข้อมูลตัวอย่างอยู่แล้ว)
   ```
   python fill_forms.py --make-template ข้อมูล.xlsx
   ```
2. กรอก 2 ชีท
   - **ข้อมูลทั่วไป**: เลขประจำตัวฝึกหัดงาน ชื่อผู้ฝึกหัดงาน ข้อมูลผู้สอบบัญชี/สำนักงาน วันที่เขียนแบบ ฐานะที่ฝึก และความเห็นของผู้ให้การฝึก
   - **รายละเอียดงาน**: 1 แถวต่อ 1 งาน (หรือต่อ 1 วัน สำหรับแบบที่เกิน 1,500 ชม.)
3. รันโปรแกรม
   ```
   python fill_forms.py ข้อมูล.xlsx
   ```
   จะได้ไฟล์ `output/แบบ ผส.2 - <ชื่อ>.pdf` และ `output/แบบ ผส.3 - <ชื่อ>.pdf`

## สิ่งที่โปรแกรมคิดให้

- **เลือกตารางให้เอง**: ถ้าชั่วโมงรวมไม่เกิน 1,500 ชม. ใช้ตารางหน้า 2/3 (ระยะเวลาเป็นช่วงวันที่) ถ้าเกิน ใช้ตารางหน้า 3/3 (รายวัน มีเวลาเริ่มต้น/สิ้นสุด และวันที่ผู้สอบบัญชีลงนาม)
- **ชั่วโมง**: ถ้าเว้นช่องจำนวนชั่วโมงไว้ จะคำนวณจาก เวลาสิ้นสุด − เวลาเริ่มต้น แล้วหักพักกลางวันให้ (ค่าเริ่มต้น 1 ชม. เฉพาะวันที่ทำงานคร่อม 12.00–13.00 น.) ตั้งค่าได้ในชีทข้อมูลทั่วไป
- **ต่อใบ**: ถ้าหน้าเดียวไม่พอ จะเพิ่มหน้าตารางให้ ช่อง "รวม" ของหน้าที่ยังไม่จบจะเป็นยอดสะสมพร้อมคำว่า "(ยกไป)" ส่วนหน้าสุดท้ายเป็นยอดรวมทั้งหมด
- **ชื่อธุรกิจ**: ถ้าหลายแถวติดกันเป็นธุรกิจเดียวกัน จะแสดงชื่อ/ที่ตั้งเฉพาะแถวแรก (และแสดงซ้ำเมื่อขึ้นหน้าใหม่)
- **วันที่**: พิมพ์เป็น พ.ศ. ให้เอง ใน Excel กรอกเป็นวันที่ปกติ หรือพิมพ์ `31/12/2567` ก็ได้
- **ระยะเวลาฝึก**: ถ้าไม่กรอก "ฝึกตั้งแต่วันที่ / ฝึกถึงวันที่" จะใช้วันแรกและวันสุดท้ายในตาราง

## หมายเหตุ

- ใช้ฟอนต์ที่มากับ PyMuPDF (Noto Serif Thai) จึงไม่ต้องติดตั้งฟอนต์เพิ่ม ฟอนต์อย่าง Sarabun / TH Sarabun ต้องยกวรรณยุกต์ขึ้นด้วย GPOS ซึ่ง MuPDF วางไม่ได้ วรรณยุกต์ที่อยู่บนสระ (เช่น "นี้" "ที่") จึงหาย
- ตำแหน่งช่องหาจากข้อความในฟอร์ม (เช่น "เขียนที่", "เลขทะเบียน") แล้วพิมพ์ทับเส้นจุดถัดไป ถ้าสภาฯ ออกฟอร์มฉบับใหม่ ให้เปลี่ยนไฟล์ `forms/ps2-ps3-blank.pdf` แล้วลองรันดู ถ้าหาช่องไม่เจอ โปรแกรมจะแจ้งชื่อช่องนั้น
- ข้อความที่ยาวเกินช่องจะถูกย่อตัวอักษรลงให้พอดี ถ้าต้องย่อเกินครึ่งหนึ่ง โปรแกรมจะแจ้งให้ย่อข้อความเอง
