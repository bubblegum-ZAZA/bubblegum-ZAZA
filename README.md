### สวัสดี 👋

นักบัญชีจากสำนักงานบัญชี ดูแลบัญชีและภาษีให้ลูกค้าหลายบริษัท
งานซ้ำ ๆ ที่เสียเวลาทุกเดือน เลยเขียนโปรแกรมให้มันทำแทน — ตรงนี้คือที่เก็บเครื่องมือพวกนั้น

**ทำเพื่อคนทำบัญชีด้วยกัน: ลดเวลาคีย์ ลดเวลาไล่หาเอกสาร เหลือเวลาไว้ตรวจของที่สำคัญจริง**

---

#### 🧰 เครื่องมือที่ใช้งานจริงในสำนักงาน

| เครื่องมือ | ช่วยงานอะไร |
|---|---|
| **[โปรแกรมโหลดใบเสร็จ](https://github.com/bubblegum-ZAZA/-)** | ล็อกอิน e-Filing สรรพากร / e-Service ประกันสังคม แล้วโหลดภาพแบบ + ใบเสร็จของลูกค้าทุกบริษัทให้ทีเดียว ตั้งชื่อไฟล์ตามบริษัท-แบบ-เดือนให้เอง |
| **โปรแกรมกระทบยอด FORMULA** | อ่านงบทดลอง / แยกประเภท / สมุดรายวันที่ export จาก FORMULA แล้วตรวจ 10 เรื่อง — ภาษีซื้อ-ขาย, หัก ณ ที่จ่าย, ประกันสังคม, ธนาคาร, เงินเดือน, ลูกหนี้-เจ้าหนี้ ถ้าไม่ตรงบอกสาเหตุที่น่าจะเป็นให้ด้วย |
| **บอทคีย์บัญชี** | รับไฟล์ Excel แล้วคีย์ใบสำคัญจ่าย / รับ / รายวันเข้า FORMULA ให้อัตโนมัติ (AutoHotkey) |
| **ย้ายยอดเข้างบ** | ดึงยอดเคลื่อนไหวรายเดือนจาก Express เข้าไฟล์งบประมาณการ / ภ.ง.ด.51 |

#### 📚 งานที่ถนัด

- ปิดบัญชีรายเดือน / รายปี ในโปรแกรม **FORMULA** และ **Express**
- ภาษี: ภ.พ.30, ภ.ง.ด.1 / 3 / 53, ภ.ง.ด.50 / 51
- เงินเดือน + ประกันสังคม, กระทบยอดธนาคาร, ตัดจ่ายเจ้าหนี้ / ตัดรับลูกหนี้

#### 💻 เครื่องมือที่ใช้เขียน

`Python` · `Playwright` · `AutoHotkey` · `Excel / openpyxl`
